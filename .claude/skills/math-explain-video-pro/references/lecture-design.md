# 讲解设计卡（写分镜前必读）

目标四个词：**直观、正确、详细、不啰嗦**。画面负责"看懂"，口播负责"想通"，板书负责"记住"——三者分工，不互相复述。

## 零、两条铁律（2026-09-30 高中老师看片后定）

**1. 给了参考答案：优先顺着答案的思路讲（方法一）；有别的好方法，作为"方法二"补充。**
- 方法一：先把答案拆成步骤清单（每一步：用了什么公式/性质、得出什么式子），分镜按清单逐步讲，板书照答案的式子写；
  只把答案一笔带过的地方讲细（"为什么递减""为什么取不到"、答案只写"略"的证明）。
- 方法二（可选）：方法一讲完后单开一小节（标题写明"方法二"），简短讲另一种思路，点出它和方法一、和前面小问的联系
  （例：用第（ⅰ）问证明的周期把区间搬回来，代替答案的诱导公式）。方法二是补充，不替换方法一，结论与方法一一致。
- 没给答案才自己解，并用第二种方法验算。
（2026-09-30 用户："在提供了答案的情况下优先顺着答案的思路讲解，当然如果你有其他方法可以作为方法二补充"）

**2. 推理只用学生做得到的方法；电脑精准图用来做动态直观展示。**
- 推理（口播里的"所以"、板书的每一步）只照卷面上写得出的步骤走，配推理的图也用学生画得出的：题目自带的几何图；
  基本初等函数的标准图像（五点法的一个周期正弦/余弦、$y=\log_{\frac12}t$ 这类草图）；单位圆与终边；数轴与区间；
  两边取值范围的示意数轴；板书里的单调性箭头、分段讨论。
- **电脑精准图**（复合函数、和函数等学生画不准的图像）**用来做动态直观展示**（用户 9-30："电脑精准图是用来做动态直观展示的"）：
  在推出一步之后（或边推边演示），让学生"看见"它——一段图像平移一个周期和下一段重合、动点沿曲线走看增减和最值、
  区间在图像上搬家、函数图像在 x 轴上方的部分和解集对上。口播说"用电脑把图像画出来看一看"，
  **不说"从图上看出，所以……"**，也不能跳过推理直接看图下结论（v1 的毛病：先画出
  $g(x)=\log_{\frac12}(\sin x-\cos x)+\sin x+\cos x$ 的精准图再"看出"单调、周期、最小值——高中老师："不是人类能理解的方法"）。
- 高中函数题的常用"人的方法"：化一（辅助角公式）→ 换元 → 在标准正弦/余弦图（或单位圆）上找区间 → 换回；
  单调性拆成几部分，里层看标准图上那一段升还是降、外层看底数，**里外同增异减、减加减还是减**；
  周期用"终边相同、三角函数值不变"；区间不在熟悉的范围就用**诱导公式**化到熟悉的角；最值看单调区间的端点。

## 一、先做"讲解骨架"，再写任何一句口播

写骨架前先过"两条铁律"：把参考答案拆成步骤清单（方法一），想好要不要方法二；推理配的图自问"学生草稿纸上画得出吗"，
电脑精准图只安排在推理之后做动态展示。

对每一问，先回答四个问题（写在草稿里，不进成片）：

| 问自己 | 例（动点重叠题第 2 问） |
|---|---|
| 1. 学生卡在哪？ | 不知道"面积最大"在哪个时刻；想去列式算每一秒的面积 |
| 2. 直观抓手是什么？（让学生一眼看出结论的画面） | PM 与 AD 平行、一直在梯形外；PN 像刷子扫过梯形 → 重叠只增不减 |
| 3. 需要哪几个关键画面（定格）？ | 起点附近、中途、终点（PM 贴 AD、PN 贴 BC、P 在 DC 上方） |
| 4. 最后落到哪条板书？ | "10 秒时最大：重叠＝梯形 ABCD" |

**没有"直观抓手"的分析 = 念答案**。抓手必须是画面上看得见的东西（图形在动、一块在变大、两条线平行、某条线扫过……），
口播只是把学生的眼睛带过去。

## 二、全片结构（小学/初中单题，两问约 4~5 分钟；高中三小问综合题约 7~8 分钟）

1. **标题卡**（5 秒）：一句钩子，说清"这题在干什么"，不念题号。
2. **读题**（problem 版式，约 40~50 秒）：不逐字念题（字在屏上），**按条件逐条转述**，每说一个条件：题干里划亮 + 图上同步标出
   （角弧、尺寸、直角、运动箭头……）。最后把每一问的问法各说一句。
3. **每一问一个 board 场景**：
   - 开头一句把问题抛出来（"重叠部分是什么形状？"），然后**先演示、再下结论**；
   - 动态题：先完整动一遍（看全过程）→ 回到起点 → 在关键时刻停下 → 指出决定结论的线/角/块 → 板书；
   - 静态计算：作辅助线（描出）→ 标出已知（尺寸、角）→ 一步一句推出未知 → 板书列式；
   - 每问最后一句落答案，板书用 ans 答案框。
4. **想一想**（15~20 秒，可选但推荐）：一个"如果……会怎样"或"为什么恰好是……"，用同一个画面演示，
   把本题结论的**成立条件**点破（例：三角形不停下会怎样 → 重叠变小 → 所以终点最大是因为 PM 始终在外）。不出新题、不展开。
5. **总结**（summary 版式，约 20 秒）：方法链 4~5 格（每格"动作 + 一句要点"）+ 两问答案（填回括号）+ 一句口诀。
6. **结束语**（outro 版式，约 8 秒）：一句收尾（"好，这道题就讲到这里。同学们，我们下次再见！"），片尾卡出经纶学霸标志，
   说完留 2 秒再淡出——**不要讲完总结就戛然而止**（2026-09-24 用户明确要求）。

## 三、直观手段选择表

| 题型 / 难点 | 用什么让它"看得见" |
|---|---|
| 动点、平移、旋转 | 点坐标写成变量函数 + tween；timebar 显示时间；关键时刻 flag；分段结论用 bands |
| 重叠/公共部分 | `clip` 交集逐帧计算、黄色填充；边界线用 `hl` 发光线段（浅色主题为红；端点用 min/max 写成随时间变化的点） |
| 最大/最小 | meter 面积条（只增不减 / 先增后减一眼可见）+ 解释"为什么增、为什么减"的那条边 |
| 求高、求边 | 描出辅助线 + 直角记号 + 分段尺寸（3 cm · 4 cm · 3 cm 叠在 10 cm 上方） |
| 特殊三角形 | 两个 45° 角弧同时亮 → 再说"等腰直角" |
| 割补、平移拼接 | region 的点写成变量函数，tween 把一块移过去 |
| 行程、追及 | 线段 + 动点沿线走 + timebar；路程用 dim 标注 |
| 分数、比、倍数 | 条形（region 矩形）等分着色 |
| 找规律、计数 | 逐项 show，关键项 focus |
| 平行、相等 | 两条线同色（cyan/green）同时 focus；等角同时出角弧 |
| 化一、化简（公式推导） | 讲台左侧用大号公式一行行推（text `cls:"fmbig"`、`align:"left"`），关键结果换红色；诱导公式等用框起来的公式（`fmbox`）；推完收进板书 |
| 复合函数不等式（外层单调） | 推理：先画外层基本函数草图（$y=\log_{\frac12}t$）定出"里层要落在哪"（$0<t\le1$，端点虚实）→ 换元后在**五点法画的标准正弦图**上画值域带子，带子里的曲线段高亮、投影到轴上 → 加 $2k\pi$ → 换回。展示：最后用电脑画出 $f(x)$ 的精准图，x 轴上方的部分正好落在解出的区间上 |
| 周期性证明 | 推理：**单位圆**，角 $x$ 的终边交圆于 $P$，再转一整圈（`pcurve` 画螺线箭头）回到 $P$ → 三角函数值不变；定义域条件（如 $\sin x>\cos x$）画成直线 $y=x$ 上方。展示：电脑精准图上一整段图像平移一个周期，和下一段重合 |
| 单调性（复合、和函数） | 推理：拆成几部分，每部分**里层的角**在标准正弦/余弦图上标出那一段、加粗（看升降），外层基本函数草图上标出对应段；板书写"①里：递增；①外：递减 ⇒ ①递减""②：递减"，再合成。展示：精准图上动点沿这一段走，看出递减、端点值 |
| 区间不在熟悉的范围 | 方法一（答案）：代入后用**诱导公式**把角化到熟悉的函数（$\sin(\alpha+\frac{3\pi}{2})=-\cos\alpha$），公式推导区一行行写，再按上一行的"单调性"做。方法二：用前面证出的周期把区间搬回熟悉的一段，精准图上区间搬家的动画做展示 |
| 物理：浮力、液面变化（称重法） | 推理：整体受力示意图（隔离法，向上两个箭头之和 = 向下的）→ 示数 = 总重 − 浮力；阿基米德原理倒推体积；水的体积 + 排开体积 = 底面积 × 水深。展示：装置按真实数据逐帧算（传感器下移 → 珠子入水 → 水面上升，示数、水深实时读数），关键时刻停住；"升起的那一层"涂色 = 排开的体积 |
| 物理：位置关系（传感器下移多少） | 方法一照答案算底端高度；方法二"盯住水面"：本来要下移的距离被迎上来的水面抵掉一部分，用两段尺寸标注（1 cm + 0.5 cm = 1.5 cm）画出来 |
| 一题多图（图①②③）、改条件 | 同一个图形用形状变量 tween 过去（弦图 → 图① → 图② → 图③），不换图；"想一想"里把关键条件去掉（AH≠HE），让图变形，看结论为什么不成立 |
| 证中点、三点共线 | 推完全等后做动态展示：把一个三角形绕中心转半圈（`fBEOr` 类 polygon + 旋转变量），正好和另一个重合 |
| 面积比（等高、中线） | 推理：作高（虚线 + 直角记号 + h₁、h₂ 标签），把面积拆成"底 × 高"；展示：改一个长度（HG），实时读数显示比值和面积比一起变，停在题目要求的那一刻 |
| 电阻网络（对称、等势） | 推理：上下翻转 → 网不变、C、D 对调 → 等势；沿中垂线对折 → 中线电压一半 → 结点不交换电流 → 可拆开 → 三路并联；未知部分整体设 $R_0$。展示：真实电流的点子流动（零电流的线点子不动，顺带看出其他等势对） |
| 动点分段（压轴题） | 推理：先定"有交点"的范围（首次碰到、最后离开的时刻），再找分段点=图形某个顶点落到曲线上的时刻（一个个列出来）；每段看交点在哪条边，横边取纵坐标、竖边代抛物线（答案每段就是这样算的，这句话是学生最缺的"怎么想到"）。展示：推完后 t 连续变化，交点实时换边，旁边同步描出 f 随 t 的图像，再画 f=常数的横线，交点正好是解出的 t |
| 分段解方程 | 一张表：分段 ｜ 列方程 ｜ 解 ｜ 检验（在不在这一段），逐行出现；最后一行下面写答案 |
| 竞赛题、答案跳步 | 答案一句"相当于……并联"带过的地方，正是学生卡住的地方：单开一个场景讲"为什么能这样看"，再回到答案的列式 |
| 选择题（逐项判断） | 每个选项一个场景，场景名"A：……"，每项最后一行板书写"×× 错 / 对"；正确项放最后讲透，最后一行"故选 ×" |
| 存在/任意（双变量恒成立） | 一根值轴上并排两根"取值条"（最低点标出，示意图不是函数图像），挑一个值的点在条上滑动；分 $a$ 的正负时条跟着变 |

## 四、口播规则（配音默认 Gemini Erinome 原版音色，整片一次合成，每句后自动加短停顿）

- **一句一件事**，主体 10~18 字，硬上限 30 字；句号收。说完一个结论可在句尾加 `｜` 停 1 秒让学生看图。
- **画面比口播早半拍或同步**：用锚点把"出现"钉在关键词上；说到"PN"时 PN 那条线正好亮。
- 口播说"为什么"，板书写"是什么"：不把板书念一遍，不把刚演示过的再复述。
- 数字写阿拉伯数字，算式可直接写 `(4+10)×3÷2`（自动转读法）；字母、∠、° 直接写（∠ 读"角"）。
- 高中符号直接写：`sin x−cos x`、`π/4`、`√2/2`、`x₁`、`g(x+2π)`、`−a/2`、`a≥2`（自动转成 sine、4分之π、2分之根号2、x一……）；
  区间别让它念（"[1,+∞)"），口播改说"大于等于1，没有上限"，区间写在板书里。
- 自问自答至少一处（"什么时候形状会变呢？"），但不要每句都问。
- 允许的口语连接：那么、所以、再看、这时、看、好。**禁用**：首先/其次/此外/综上所述/值得注意的是/让我们/不难发现/由此可见
  以及"掌握了这个方法，这类题就……"式收尾。
- 不念题号结构（"第一小题的第一个空"），不说"接下来我们将"。
- 时长预算：读题 ≤ 50 秒；每问分析 40~60 秒；计算 ≤ 50 秒；想一想 ≤ 20 秒；总结 ≤ 25 秒。check 会报总字数与估算时长。

## 五、板书规则

- 每行一个结论或一个算式，≤ 26 字（宽约 550px），长算式拆两行，第二行用 `$\phantom{S}=21$` 对齐等号。
- 结论用 key（浅色主题红字），答案用 ans（青色框，配 `np: "（1）"`），补充说明用 sub（灰色小字）。
- 算式、字母一律 `$..$`；中文标点全角；单位写在全角括号里：`$10\div1=10$（秒）`。
- 一个场景 3~5 行为宜；场景切换板书清空（每问独立）。

## 六、画面规则

- **配推理的函数图，学生都要画得出**（见"零、两条铁律"）：标准函数用五点法先点出关键点再连线，比直接甩出一条精确曲线更像老师在黑板上画。
  电脑精准图放在推理之后做动态展示（平移、动点、区间搬家），口播点明"用电脑画出来看一看"。

- 世界坐标用题目真实数据；视野留出标签和尺寸的位置（尺寸在下方要给 y 留 -2 左右）。
- 同一时刻只让一处在"动"或"亮"；动画中途不要同时出板书长句。
- 标签被线压住或互相挤：改 `dir` / `dist`，或把形状名放到图形下方（`["cx('ov')", -1.5]`）。
- **动点停下来的那一刻最容易撞字母**（9-30 函数压轴题成片里撞了 5 处）：动点的停顿值别取在分段点、定点正旁边——
  停在 t=3.2 时 P 的字母压到 B 点上，停在分段点 t=(3−√17)/2 时 M 与 E 重合、两个字母叠成一团；把停顿值挪开一点
  （3.45、−0.45）就好，讲法不受影响。实在挪不开，就给那一拍另备一个换了 `dir` 的同名标签（先藏旧的、再显新的）。
  动点经过的直线，名字放在点的字母**另一侧**，或离线远一些（字框最近的角离线 ≥45 像素）：点的字母本身离线约 28 像素，
  放在同一侧的直线名字会在点经过时把它盖住。成片里逐拍抽帧，放大看字母附近。
- 图形往右动出画框、钻到板书面板下：给该场景设 `view` / camera 把视野平移过去。
- 预览（preview）每个节拍定格一帧：逐张看——标签重叠、文字出界、强调没对准、板书折行都在这里改掉。
