# 分镜 JSON 规格（讲题视频 Pro）

一份分镜 = 一道题的完整视频。脚本只做确定性的事（排版、配音、对时、渲染），**讲什么、画什么、何时动**全在分镜里。
完整样例：`examples/dongdian-chongdie.json`（动点问题：三角形平移与梯形的重叠部分，成片约 4 分半）。

```jsonc
{
  "meta":    {...},          // 标题卡、输出文件名
  "problem": {...},          // 题干（读题版式用），可划重点
  "world":   {...},          // 几何世界：变量、点、图元（整片共用一个世界，镜头可推拉）
  "widgets": {...},          // 可选：时间条、面积条
  "layouts": {...},          // 可选：覆盖默认画框
  "scenes":  [...]           // 场景序列，每个场景由若干"节拍"（一句或几句口播 + 同步动作）组成
}
```

## 1. meta

| 字段 | 说明 |
|---|---|
| title | 标题卡主标题（一句话点出题目在干什么，≤14 字） |
| tag | 题型标签，如"动点问题""行程问题" |
| subtitle | 标题卡副标题，一般是两问的问法压缩 |
| out | 成片文件名（落在分镜同目录） |
| fps | 默认 30 |
| subtitles | 默认 true（底部字幕；outro 片尾卡自动不出字幕） |
| theme | `light`（默认：浅青灰桌面 + 方格纸 + 经纶学霸青色标志）或 `dark`（墨蓝网格底，白色标志） |
| tts | 可覆盖 `scripts/tts_config.json` 的任意项（voice / rate / break …） |

## 2. problem（读题版式用）

```json
"problem": {
  "tag": "动点问题",
  "text": "如图，在{k1|等腰梯形 $ABCD$} 中，{k2|$\\angle DAB=45^\\circ$}，……",
  "parts": ["（1）{q1|……由（　　）形变为（　　）形}。", "（2）……"]
}
```
- **题干原文一字不改**，只加标记。标点全角；字母、算式写进 `$..$`（KaTeX）。
- `{id|文字}` = 可划重点的片段，动作 `{"mark": "id"}` 让它像荧光笔一样扫亮；最近一处最亮，之前的变淡。
  标记里可以包公式（`{k1|$f(x)=\\log_{\\frac{1}{2}}(\\sin x-\\cos x)$}`），公式里的花括号不算标记边界。
- 填空括号用 `（　　）`（两个全角空格）。
- 分数一律 `\\dfrac`（行内 `\\frac` 在视频里太小），只有对数底数这类下标里的 `\\frac12` 保留小号。
- `"size": 34`：题干字号（默认 33）。纯代数题读题时不放图：读题场景写 `"world": false`，
  并给它与下一场景相同的 `box`、`view`，免得图从题干位置飞过去。

## 3. world（几何世界）

```json
"world": {
  "vars":   {"t": 0},                         // 可补间的变量（动点的时间、旋转角……）
  "view":   {"x": [-11.2, 11.2], "y": [-2.1, 5.9]},   // 默认视野（世界坐标）
  "points": {"A": [0, 0], "N": ["t", 0], "P": ["t-5", 5], "K1": ["min(t/2,3)", "min(t/2,3)"]},
  "objects": [ ... ],                         // 数组顺序 = 绘制层次（后画的在上面）
  "init":   ["trap", "tri", "lA"]             // 一开始就可见的图元
}
```
- **坐标按题目真实数据取**（厘米就用厘米数），画面上的一切位置都是算出来的，不许目测摆。
- 点坐标可写表达式：变量名、`+-*/`、`min max abs sqrt sin cos PI` 等 Math 函数，
  以及 `area('图元')`、`cx('图元')`/`cy('图元')`（形心）、`px('点')`/`py('点')`。
- 动点：把点写成变量的函数，动作里补间变量，整张图就按真实几何关系动起来。
  分段变化的点（如重叠部分的拐点）用 `min/max` 写成一个式子。

### 图元类型

| type | 必填 | 说明 |
|---|---|---|
| polygon | pts | 多边形（描边 + 淡填充）。三角形、梯形等主体图形 |
| region | pts | 只填充不描边的区域（割补块、强调某块） |
| clip | of:[id,id] | 两个多边形的**交集**，逐帧精确计算（重叠部分）。第一个可非凸，裁剪用的须凸 |
| segment | pts:[P,Q] | 线段；`ext:[a,b]` 两端延长；`dash` 虚线 |
| polyline | pts | 折线 |
| arrow | from, to | 箭头（运动方向等） |
| angle | pts:[A,O,B], text | 角弧 + 度数；`r` 半径 px，`lr` 标签距离 |
| right | pts:[A,O,B] | 直角记号；`size` px |
| dim | pts:[A,B], text | 尺寸标注（两端箭头 + 文字）；`off` 偏移 px：**正 = A→B 左手侧（从左到右时在上方），负 = 下方** |
| point | at | 点（圆点），常用来闪一下关键点 |
| label | at, text | 点名标签；`dir` N/S/E/W/NE/NW/SE/SW，`dist` px；重叠的标签自动左右推开 |
| text | at, text | 图上的文字（形状名、速度说明）；`cls`: `wt` 楷体 / `shape` 粗黑体 / `fm` 公式（白底衬）/ `fmb` 公式（无底）/ `fmbig` 大号公式（推导区）/ `fmbox` 框起来的公式（诱导公式等）；`align:"left"` 以 at 为左端对齐（几行推导左对齐时用，配 `"dir":"C"`）；公式里可用 `\\color{#7b61d1}{...}` 给部分上色 |
| curve | fx, x:[起,止] | **函数图像**：`fx` 是 x 的表达式（可用变量、`sin cos log sqrt PI…`，`log` 是自然对数，`log(t)/log(0.5)` 即以 1/2 为底）。只在镜头看得见的那段取样；超出视野上下沿截掉、出入处补到边沿；函数无定义（NaN）处自动断开（对数、渐近线）。`ymin/ymax` 只画某个范围内的部分；`n` 取样点数（默认 480，长曲线给 900~1200）。描出动画从左往右扫 |
| pcurve | fx, fy, t:[起,止] | **参数曲线** $x=f_x(t),\ y=f_y(t)$：单位圆（`"fx":"40+1.7*cos(t)","fy":"1.7*sin(t)","t":[0,"2*PI"],"close":true`）、角弧、转圈螺线；`arrow:true` 末端加箭头（转的方向）；t 的区间可写变量，tween 它就是"转起来"；`n` 取样数（默认 240） |
| axes | x:[起,止], y:[起,止] | 坐标轴（带箭头）；`origin` 原点（默认 [0,0]）；`xlabel/ylabel/olabel` 轴名（默认 $x$ $y$ $O$，写 "" 不显示）；`nox/noy` 只画一根；`xlabelDir:"N"` 轴名 x 放轴上方 |
| ticks | axis:"x"/"y", at:[…], labels:[…] | 刻度 + 刻度值（KaTeX）；`on` 刻度所在的另一坐标（默认 0）；`dir` 标签方向（x 轴默认 S、y 轴默认 W）、`dist` 距离 px。分几组写，讲到哪组显哪组 |

点引用（pts / at / from / to）可以是：点名、`[x表达式, y表达式]`、`mid(A,B)`、`lerp(A,B,k)`、
`off(A,dx,dy)`、`centroid(图元id)`、`foot(P,A,B)`（P 到直线 AB 的垂足），可以嵌套（`mid(O,foot(O,M,D))` = 高的中点，放高的标签）。
curve / pcurve 的表达式里也能用 `px('M')`、`py('M')`（例：以 M 为圆心、MA 为半径的圆）。

**一题多图（图①②③）的写法**（样例 `04_赵爽弦图`，`make_sb.py` 生成）：所有点写成几个形状变量的函数（例：BE、AH、HE、HG 四个长度 +
整体转角），一张图变到下一张图就是 tween 这些变量——学生看到的是同一个图形"变形"过去，关系（全等、平行、中点）一路保持。
点坐标里的公共计算放 `world.funcs`（例：旋转 `rx/ry`）。

**板书面板的大小可以按场景改**（2026-09-30 函数压轴题）：场景写 `"notes": {"x": 930, "w": 922}` 把面板加宽（配 `"box": {"x":70,"y":140,"w":830,"h":800}`
把图框收窄），公式长的分段式一行写得下；写 `"notes": false` 不要面板，图框用全宽 `{"x":70,"y":140,"w":1780,"h":800}`（大表格、终场动画）。
也可以在 `layouts.board.notes` 统一设。注意：全宽图框比视野宽时，视野两边的世界内容也会露出来（例如坐标轴），用不上的要 hide。

**动点压轴题写法要点**（样例 `06_函数压轴`）：交点这类"要分情况才算得出"的量，放进 `world.funcs` 用 JS 按几何直接算
（例：正方形四条边与抛物线的交点 `IS(t)`，M、N 取最左、最右两个），点坐标写 `["MX(t)","MY(t)"]`——t 一动，交点自动换边，
和分段讨论的结论逐帧一致；再用 `curve` 画出"f 随 t 变化"的图像（`fx` 里调 `FV(x-平移)`、`x` 的终点写变量，边走边描）。
先用 Python 把分段式和直接几何计算对一遍（样例 `make_sb.py` 的思路：6.8 万个 t 全部一致才写分镜）。

**电路题写法要点**（样例 `05_电阻网络`，`make_sb.py` 生成）：
- **电流点子**：线段加 `"dash": [0.1, 17]`（圆头 → 一串点）和 `"flow": "ft*速度"`（沿线走过的距离，px；正 = 从 pts[0] 流向 pts[1]，负 = 反向），
  tween `ft` 点子就顺着线走，走得快慢 = 电流大小。电流值别目测：在 make_sb.py 里用 numpy 把整张网按节点电压法解出来，
  **只写真实电流**（9-30 解出来才发现：演示网里除了 C、D 间那根，四个角上的四根也是零电流——差点口播"只有这一根没电流"）。
- 口播里字母读音相同的（电阻 r 和 R）用 `{显示|读法}`：`{r|小r}`、`{R|大R}`、`{R′=R|R撇等于大R}`；
  长分式也用它，`{R″=2rR/(2r−R)|R两撇等于 2小r减大R 分之 2小r大R}`（字幕显示前一半，配音念后一半）。
- 电路图（等效电路）用 polygon 当电阻方框（`fill: "paper"` 盖住导线）+ segment 当导线，画在世界另一块地方，镜头移过去。

**物理装置题写法要点**（样例 `03_珠串浮力`，用 `make_sb.py` 生成分镜——同样的珠子、刻度多，用脚本写比手写 JSON 稳）：
- `world.funcs`：分镜自带的 JS 辅助函数（源码字符串），在同一作用域依次定义、可互相调用，表达式里直接用。
  要解方程才知道的量放这里，例：水深 `Hw(yb)`（水的体积 + 水下珠子体积 = 底面积 × 水深，二分法解）、浸没颗数 `Nf(yb)`。
  函数名别和变量、`H`/`v`/`FN`、Math 函数重名。
- 实时读数：text 的文字里写 `{#}`（放在 `$..$` 外），配 `num`（表达式）和 `digits`（小数位），逐帧显示数值，
  如 `"text": "{#} N", "num": "1.6-0.1*Sub(yb)"`（传感器示数）、`"水深 {#} cm"`。`cls`: `lcd` 仪器显示屏（深底亮字）/ `rd` 图上读数。
- text 的 `align: "right"`：以 at 为右端对齐（读数贴在杯壁左边时用）。
- 闭合的 `pcurve` 可填色（`close: true` + `fill`）：椭圆珠子、气泡。
- `world.clip`（px）：图只画在画框里（加这个边距）。装置高、推近景时伸出画框的部分会被裁掉，不压标题和板书。
- `problem.width`：题干收窄（图放在题干右侧时），读题场景给 `box`（右侧）和 `view`。
- 口播里的物理单位直接写：`1.5 N`、`600 Pa`、`10 N/kg`、`1.0×10³ kg/m³`、`20 cm²`、`110 cm³`，自动读成牛、帕、牛每千克……；
  公式符号（ρ、F浮、V排）别写进口播，用"水的密度""浮力""排开水的体积"。

**函数题写法要点**（样例 `02_对数三角综合`；先读 lecture-design.md "两条铁律"：配推理的图学生画得出，电脑精准图只做推理之后的动态展示；
方法二单开一个 board 场景，`title` 写"方法二：……"）：
- 不同的图放在同一个世界的不同位置（如标准正弦图在 x∈[0,2π]、外层对数草图在 x≈8.3 处平移过去、单位圆在 x=40、取值条在 x=60），
  换场景时 `view`/`camera` 移过去即可；公式推导区放在讲台左上，写完 hide、收进板书。
- 视野写 `"free": true`：横纵各自铺满画框（x 按弧度、y 范围小时不必同比例）；`camera` 也可带 `"free": true`。
- 表达式里 `vx(0)/vx(1)`、`vy(0)/vy(1)` 是当前视野的左右/下上边：坐标轴 `x: ["vx(0)+0.1", "vx(1)-0.15"]`、
  值域带子 `region pts: [["vx(0)",0],["vx(1)",0],["vx(1)",1],["vx(0)",1]]` 会跟着镜头伸缩。
- 空心点（取不到的端点）：point 加 `"hollow": true`。
- 分段/周期的高亮用条件表达式：`"(t>0 && t<=1) ? t : NaN"` 画出所有周期里落在带子里的曲线段，`? 0 : NaN` 画它在 x 轴上的投影。
- 整段图像平移（证周期、周期搬区间）：把平移量做成变量，`fx` 写 `g(x-sh)`、`x` 写 `["PI/4+sh", "5*PI/4+sh"]`，tween sh。

### 样式字段

`stroke`、`fill` 用色名：`ink`（默认线/字色，浅色主题为墨色）`blue orange yellow gold green red gray cyan(=teal) purple`，
以及语义色 `hl`（讨论中的边界，浅色主题=红）、`focus`（默认强调色）；或 `#hex`。
**浅色主题下 yellow 只做填充**（重叠区、面积条），文字、角弧、描边用 `gold`，否则白底上看不清；`white` 在浅色主题里等同 ink。
`width` 线宽 px；`fillOpacity`；`dash`（true 或 `[8,8]`）；`opacity`；`glow` 常亮光晕；
`color`（label/text 文字色）；`lcolor`（角/尺寸文字色）。

**颜色语义（整片统一，别随手换）**：固定图形 blue ｜ 运动图形 orange ｜ 重叠/所求结果 yellow 填充 + gold 文字 ｜
正在讨论的边界 hl（红色发光）｜ 平行/相等关系 cyan 或 green ｜ 反例/变小 red ｜ 辅助线 ink 虚线、尺寸 gray。

## 4. widgets（可选部件，讲台版式左下）

```json
"widgets": {
  "timebar": {"var": "t", "from": 0, "to": 10, "unit": "秒", "tick": 1, "label_every": 2, "name": "时间",
     "bands": [{"id": "b1", "from": 0, "to": 6, "text": "三角形", "color": "yellow"}],
     "flags": [{"id": "f6", "at": 6, "text": "$PN$ 过点 $D$"}]},
  "meter": {"expr": "area('ov')/area('trap')", "name": "重叠面积", "full": "＝整个梯形"}
}
```
- timebar：变量的进度条 + 当前值，随补间实时走；`bands` 分段着色（形状分段的结论）、`flags` 关键时刻旗标，都要用 show 动作显出来。
- meter：一个 0~1 的表达式做成的量条（面积占比等），`full` 是满格时可 show 的说明。
- 部件本身也要 `{"show": "timebar"}` 才出现。

## 5. scenes

| layout | 画面 | 额外字段 |
|---|---|---|
| title | 标题卡（tag / title / subtitle 取 meta，自动入场） | — |
| problem | 章节头 + 上方题干（可划重点）+ 下方几何图 | num（默认"题"）、title（默认"读题"）、tag（默认 problem.tag） |
| board | 章节头（青色编号块 + 标题 + 标签），左侧几何图（+部件卡片），右侧"板书"卡片 | num, title, tag, view |
| summary | 方法链 + 答案卡 + 口诀 | chain, answers, tagline |
| outro | 片尾卡：居中经纶学霸标志 + 结束语，自动入场，说完后全片缓缓淡出（**每片必须有，别戛然而止**） | main（默认"这道题就讲到这里"）、sub（默认"我们下次再见"） |

- 左上角经纶学霸标志、右上角章节进度条是全片常驻外框，引擎自动画（标志素材 `assets/brand/`，浅色用青色字版）。

- 同一个世界在 problem → board 之间**不重建**：图会从题干下方平滑搬到讲台左侧，保持连续感。
- board 场景的 `view` 是本场景开始时的镜头（不写就继承上一场景）；场景内用 camera 动作推拉。
- summary：`chain` = `[{id, title, sub}]` 方框链（show 方框时自动先画箭头），`answers` = `[{id, text}]`（`[[答案]]` 标黄），`tagline` 一句口诀（id 为 `tagline`）。
- 文本里 `\n` 换行。

## 6. beats（节拍）与动作

```json
{"say": "这时，重叠部分由 AB、AD、PN 三条线围成。",
 "do": [{"at": "AB", "show": "eBot", "dur": 0.5}, {"at": "AD", "show": "eLeft"}, {"at": "PN", "show": "eRight"}],
 "hold": 0}
```
- `say`：一句或几句口播，**以 。？！ 结尾**；句尾加全角 `｜` = 多停约 1 秒（揭晓前、切换前用）。
- `do[].at`：锚点——口播里的一个词，配音读到它的第一个字时动作开始。缺省 / `"^"` = 本节拍开口时；`"$"` = 本节拍说完时；
  `"词#2"` = 本节拍里第 2 次出现。锚点可含字母数字（按读音匹配：`"45"` 匹配"四十五"）。`delay` 再往后推几秒。
- **节拍会自动等动画**：某个动作比口播长（如 7 秒的平移），下一句会等它做完再开口（配音里插静音）。
  不想等就给该动作 `"wait": false`；想多停几秒思考就给节拍 `"hold": 秒`。

### 动作（每个动作只能有一个操作键）

| 操作 | 写法 | 说明 |
|---|---|---|
| show | `{"show": id 或 [ids], "fx": ..., "dur": ...}` | 出现。fx 缺省按类型：线类 draw 描出、点 pop、面/字 fade、板书/划线/答案 wipe 擦入、方框 pop |
| hide | `{"hide": [...]}` | 淡出 |
| focus | `{"focus": [...], "color": "gold", "dur": 1.5}` | 临时强调：变色加粗发光，dur 后自动恢复（不写 color 用默认强调色） |
| paint | `{"paint": [...], "color": "...", "width": 5}` | 永久改色/改线宽 |
| dim | `{"dim": [...], "to": 0.25}` | 压暗（`to: 1` 复原） |
| tween | `{"tween": {"t": 6}, "dur": 2.8, "ease": "linear/inout/out/in"}` | 变量补间——**动画的主力**，dur 必填 |
| set | `{"set": {"t": 0}}` | 变量瞬间赋值 |
| camera | `{"camera": {"x": [..], "y": [..]}, "dur": 1.2}` | 推拉镜头（世界坐标视野） |
| note | `{"note": "文字 $公式$", "cls": "key/ans/sub/blue", "np": "（1）"}` | 板书加一行（擦入）。ans = 答案框（浅色主题青框），key = 结论（浅色主题红字），sub = 灰色小字；`gap` 上方多空一点；`sm` 小一号（长答案用，如 `"ans sm"`）；文字里 `\n` 换行 |
| mark | `{"mark": "k1"}` | 题干划重点 |

id 可以是图元 id，也可以是界面元素 id：题干标记 id、板书 note 的 `id`、部件 `timebar/meter/mt-full`、bands/flags 的 id、
chain 的方框 id、answers 的 id、`tagline`。
